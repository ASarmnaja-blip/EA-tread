## 5. สิ่งที่ขอให้ Codex ตรวจ

**ก. โค้ด EA (อ่านอย่างเดียว ห้ามแก้ไฟล์ที่ demo ใช้อยู่):**
1. `BuildBars()` / `KeyOf()` / `BarOf()` ใน `G27K_Trend.mq5`:
   - ถูกต้องไหมเมื่อ H1 มีช่องว่าง (วันหยุด, ช่วงพักโลหะ, DST)
   - ตรงกับ `g768.agg` ไหม (time = เวลา H1 แท่งแรกของกลุ่ม)
2. กฎ Fed:
   - `FedParse` (rolling SD 250 ค่า min 120 shift 1)
   - `UsHoliday` เทียบกับ pandas `USFederalHolidayCalendar`
   - `FedBlock` และ `FedFirstAfter` ใช้เวลาแท่งเข้าเหมือน `news_shock.apply` ไหม
3. เงา:
   - `CheckShadow` จบไม้ถูกแท่งไหม (stop ในแท่ง k → แท่งออก k · channel → แท่งถัดไป)
   - หลังรีสตาร์ต EA จำสถานะเงาไว้ใน state file ครบไหม
4. การรอตลาดเปิด:
   - `TradeOpen()` / `InTradeSession()` กับตาราง session ของ Exness
   - มีกรณีที่ EA ค้างรอไม่จบไหม
5. Sleeve: `CheckTimeExit` นับแท่งจริง · ห้ามเข้าใหม่ก่อนแท่งออก · ลำดับ long ก่อน short

**ข. สถิติและความเสี่ยง:**
1. **ความเสี่ยง 1% ทุกชุดไม่มีเบรก ไม่ได้ลงทะเบียนทดสอบไว้ก่อน:**
   - จำลอง 15 ปี (spread Cent + swap D): 86.6% ต่อปี · Balance DD 46.7%
   - ถ้าทุกไม้แย่ลง 0.10R: 28.6% ต่อปี · DD 70.6%
   - ช่วยเสนอเกณฑ์หยุด/ลดความเสี่ยงสำหรับ forward test ที่ตั้งไว้ล่วงหน้า (เช่นเทียบ R สะสมกับแถบคาดการณ์)
2. **swap ของ crypto:**
   - กรณี D ใช้จุด swap วันนี้ย้อนหลัง เท่ากับ swap 70–116% ต่อปีในปี 2017–20
   - กรณี C ใช้ % คงที่ ความจริงอยู่ตรงไหน มีวิธีหาประวัติ swap ของ Exness ไหม
3. **เงิน M30 ที่ spread Cent:** การชน SL/TP ด้วย bid/ask แพงกว่าโมเดลราว 0.037R ต่อไม้ (วัดบน 105 ไม้) ควรปรับโมเดลไหม
4. **ข้อเท็จจริงจากงานวิจัยเดิม:** ทั้งโครงการทดสอบราว 32 ล้านสมมติฐาน และ G27K #1 เลือกโดยเห็นผลปี 2021–26 ตัวเลขทั้งหมดจึงเป็นเพดานบน

**ค. forward test:** ออกแบบการเทียบรายสัปดาห์ระหว่าง log ของ EA บน demo (`MQL5\Files\g27k_*_log.csv`) กับไม้ที่งานวิจัยคำนวณจากข้อมูลใหม่ เพื่อจับ drift และความต่างของ execution
