## สิ่งที่เพิ่มหรือแก้ในรอบนี้

1. **G27K-F:**
   - เพิ่ม ETH (`SET_USD4_ETH`, `SET_CENT4_ETH`)
   - ความเสี่ยงเป็น input
   - เบรกเปิดหรือปิดได้ ค่าตั้งต้นคือปิด
2. **กฎ Fed (ตัว F ใน G27K-F):**
   - EA โหลด DGS2 จาก FRED แล้วคำนวณเองแบบเดียวกับ `news_shock.fed_shocks`: rolling SD 250 วัน, ปฏิทินวันหยุดสหรัฐ, ใช้ได้ 22:00 UTC ของวันทำการถัดไป
   - ปิดไม้ทอง เงิน BTC ETH ในชั่วโมงถัดไป และห้ามเข้า 5 วัน
3. **ไม้เงา (shadow):**
   - งานวิจัยใช้กฎ Fed โดยลบไม้หรือตัดไม้ให้สั้นลงจากรายการ G27K เดิม ตลาดจึงยังถูกจองอยู่จนกว่าไม้เดิมจะจบเอง
   - EA จึงตามไม้นั้นเป็นเงาจนถึง SL หรือ channel exit ของมันเอง และไม่เข้าไม้ใหม่ในระหว่างนั้น
4. **แท่ง H4 ของ G27K-F เริ่ม 22:00 UTC:**
   - รายงานวิจัยทุกฉบับรวม H1 เป็น H4 ที่ 22/02/06/10/14/18 UTC (`g768.frames`) แต่แท่ง H4 ของ MT5 เริ่ม 00:00
   - EA สร้างแท่งเองจาก H1 (`InpH4StartHour=22`) ให้ตรงกับไม้ที่รายงาน
   - HANDOFF §3.1 เขียนว่า "ขอบแท่ง 00 UTC" ซึ่งไม่ตรงกับไฟล์ไม้ของงานวิจัยเอง
5. **ไม้ M30 แก้บั๊กของผม 2 ข้อ:**
   - สัญญาณต้องมาจากแท่งหลังแท่งที่ไม้ก่อนจบ (`no_overlap`: s > แท่งออก) ก่อนแก้ EA เข้าไม้เร็วกว่างานวิจัยหนึ่งแท่ง และเทรดมากเกินไป 20%
   - long กับ short ตรวจ D1 แยกกัน
6. **ไม้ H1 (ใหม่):** ราคาอยู่ในช่วงบน/ล่าง 10% ของ 250 แท่ง + ATR14/ATR100 ≥ 1.25 + D1 ทางเดียวกัน · SL 2×ATR20 · TP 2R · ครบ 30 แท่งปิด
7. **ตลาดปิด (ช่วงพักรายวันของโลหะ หรือคืนวันศุกร์):**
   - EA ไม่ส่งคำสั่งระหว่างที่ตารางเวลาเทรดของ symbol ปิด
   - เข้าหรือออกที่ tick แรกหลังตลาดเปิด แบบเดียวกับงานวิจัยที่ใช้ราคาถัดไป
   - log หนึ่งบรรทัดต่อเหตุการณ์ (ก่อนแก้ ทดสอบแล้วเจอ log ซ้ำ 18,255 บรรทัด และในบัญชีจริงจะส่งคำสั่งซ้ำทุก 5 วินาที)

## ติดตั้งบน demo (ทุน 13,000 USD = กระจกของ 13,000 USC บน Cent)

1. **อนุญาต FRED:** MT5 > Tools > Options > Expert Advisors
   - ติ๊ก "Allow algorithmic trading"
   - ติ๊ก "Allow WebRequest for listed URL" แล้วเพิ่ม `https://fred.stlouisfed.org`
   - ถ้าไม่เพิ่ม G27K-F จะใช้ไฟล์สำรอง `Common\Files\g27k_DGS2.csv` (ข้อมูลถึง 30 ก.ย. 2026) และกฎ Fed จะไม่รู้ข้อมูลใหม่
2. **เปิด 3 กราฟ** (เช่น XAUUSD 3 กราฟ) แล้วลาก EA ทีละตัว: Inputs > Load > เลือก preset demo > ติ๊ก Allow Algo Trading > OK
3. **เปิดปุ่ม Algo Trading** บนแถบเครื่องมือ
4. **ตรวจแท็บ Experts หรือ log:**
   - ต้องมีบรรทัด START ของทั้ง 3 ตัว
   - G27K-F ต้องขึ้น "Fed rule download: 192 rule times …"
   - log อยู่ที่ `MQL5\Files\g27k_log.csv`, `g27k_m30_log.csv`, `g27k_h1_log.csv`

**ข้อควรรู้:**
- **lot ตรงกับ Cent:** สัญญาบน demo ใหญ่กว่า Cent 100 เท่าพอดี (ทอง 100 oz, เงิน 5,000 oz, BTC 1, ETH 1 ต่อ lot และ lot ต่ำสุดเท่ากัน) การปัด lot จึงเหมือนบัญชี Cent 13,000 USC ทุกอย่าง
- **spread ไม่ตรงกับ Cent:** demo ถูกกว่า Cent ในบางตลาด (เงิน demo ~2.7 bp, Cent 4.6 bp) ผลบน demo จึงดีกว่า Cent เล็กน้อย
- **บัญชีเงินจริง:** EA ไม่ส่งคำสั่งบนบัญชีเงินจริงจนกว่าจะตั้ง `InpAllowRealAccount=true` เอง
