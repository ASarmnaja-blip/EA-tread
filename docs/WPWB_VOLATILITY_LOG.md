# คลังช่วงตลาดผันผวน XAUUSD (WPWB volatility log)

สร้าง 2026-09-28 ตามคำขอผู้ใช้: "บันทึกหาช่วงที่ตลาดผันผวนไว้ด้วย เพราะผมอยากชนะช่วงที่ตลาด
ผันผวนด้วยความท้าทาย แต่ตอนนี้ช่วงตลาดผันผวนยังไม่ต้องเสี่ยงมาก"

**สถานะ: ข้อมูลเชิงบรรยาย ไม่ใช่ edge** ใช้เป็นวัตถุดิบศึกษาเพื่อออกแบบวิธีเทรดช่วงผันผวนในอนาคต
ตอนนี้ช่วงผันผวนใช้ vol_scale ลดขนาดไม้เท่านั้น (`docs/WPWB_RISK_REPORT_SPEC.md`)

ไฟล์เต็มรายสัปดาห์: `data/wpwb_weekly/volatility_log.xlsx` (สร้างใหม่ด้วย
`python research/wpwb_weekly/episodes.py` ทุกสัปดาห์ สัปดาห์ใหม่จะต่อท้ายเอง)

## นิยาม

- ความผันผวนรายสัปดาห์ = ผลรวมกำลังสองของผลตอบแทน H1 ในสัปดาห์ (ตัดวันศุกร์ 22:15 UTC)
- ระดับเทียบค่ากลางของ **52 สัปดาห์ก่อนหน้า** เท่านั้น (ไม่ใช้ข้อมูลอนาคต):
  สงบ < 0.87 เท่า · ปกติ < 1.22 · ผันผวนสูง < 1.58 · ผันผวนรุนแรง ≥ 1.58 (หน่วยความผันผวน)
- "ช่วงผันผวน" = สัปดาห์ผันผวนสูงขึ้นไปที่ติดกัน

## สิ่งที่พบ (2022-07 ถึง 2026-09, 221 สัปดาห์)

1. **ผันผวนสูงขึ้นไป 68 สัปดาห์ (31%) รวม 25 ช่วง** ยาวที่สุดคือ 2025-12-27 ถึงต้นเม.ย. 2026
   (15 สัปดาห์ สูงสุด 4.4 เท่าของปกติ — สัปดาห์ 24 ม.ค. 2026 มีแท่ง H1 −590 bp และกรอบ 18%)
2. **ทิศทางในสัปดาห์ผันผวนเป็นเหรียญ: ขึ้น 34 / ลง 34** — สิ่งที่ต่างคือขนาด:
   เคลื่อนทั้งสัปดาห์เฉลี่ย 257 bp เทียบ 152 bp และกรอบสูง-ต่ำ 543 bp เทียบ 300 bp
   → ความท้าทายของช่วงผันผวนคือ **ขนาดไม้และระยะ SL** ไม่ใช่การเดาทิศ
3. **พยากรณ์เตือนได้ 38/68 สัปดาห์ผันผวน (56%) แต่เตือนสัปดาห์แรกของช่วงได้แค่ 6/25 ช่วง**
   EWMA รู้ว่า "กำลังผันผวนอยู่" หลังช็อกแรกเกิดแล้ว แต่ไม่รู้ล่วงหน้าว่าช็อกแรกจะมา
   → **สัปดาห์แรกของช่วงผันผวนคือสัปดาห์อันตรายที่สุด** และระบบนี้จับไม่ได้ ต้องพึ่ง SL ที่ตั้งไว้เสมอ
4. เตือนแต่ไม่เกิด 29 ครั้ง (ส่วนใหญ่คือสัปดาห์ที่ช่วงผันผวนเพิ่งจบ) — ต้นทุนของการลดไม้โดยไม่จำเป็น
5. ช่วงผันผวนเกือบทุกช่วงมีข่าว CPI/FOMC/NFP/PCE อยู่ด้วย แต่สัปดาห์ปกติส่วนใหญ่ก็มีข่าวเหล่านี้
   **จึงยังไม่ใช่หลักฐานว่าข่าวเป็นต้นเหตุ** (ดูคอลัมน์ 3 แท่งที่แรงที่สุดในไฟล์ Excel ว่าตรงกับเวลาข่าวหรือไม่)
6. ทุกข้อข้างบนมาจากข้อมูลที่โปรเจกต์นี้ใช้มาแล้ว เป็นการบรรยาย ไม่ใช่การทดสอบ

## ใช้ต่ออย่างไร (ยังไม่ทำ ต้องตรึงกฎก่อนดูผล)

- ศึกษาช่วงผันผวนแบบแยกสัปดาห์แรกกับสัปดาห์ต่อเนื่อง — ช่วงต่อเนื่องพยากรณ์ได้ จึงวางแผนขนาดไม้ล่วงหน้าได้
- ถ้าจะหา setup สำหรับช่วงผันผวน ต้องประกาศก่อนดูผล และทดสอบกับช่วงผันผวน **ในอนาคต** ที่คลังนี้จะเก็บเพิ่มทุกสัปดาห์
