## Critical

A raw return can have nonpositive mean while its clipped value has positive mean—for example, +1 with probability 0.6 and −2 with probability 0.4. The process is valid only for the stronger sequential null  
   `E[clip(R_t,-1,1) | past] <= 0`, not for unconditional raw mean R ≤ 0. Dependence is not inherently fatal, but the required conditional-mean null is nowhere stated or justified. Fixed λ=0.2 and zero-trade weeks contributing zero are otherwise legitimate.

There is no per-week input hash, data-end hash, recorded timestamp, append-only refusal, or preserved first score. Revised broker bars therefore rewrite past “forward” outcomes.
