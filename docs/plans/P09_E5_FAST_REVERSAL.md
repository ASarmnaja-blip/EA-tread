# P09 กลับตัวไว (คลิป 4 ท่า 5)
- TF M5, M15, H1. swing high H ยืนยัน แล้วมี swing low L ยืนยันจุดแรกหลัง H (แนวรับชุดเดียว) และยังไม่มี high ใหม่เกิน H.
- สัญญาณ: close(t) < L ครั้งแรก → ขาย market. SL (หลัก) = H + 0.1 ATR; แบบรอง = high(t) + 0.1 ATR. TP 1:1. ซื้อกลับด้าน.
