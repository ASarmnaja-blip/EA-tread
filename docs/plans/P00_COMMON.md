# P00 กติการ่วมของทุกแผน (P01–P16)
เขียน 1 ต.ค. 2026 ก่อนคำนวณตัวเลขใดๆ

- **ตลาดและช่วงข้อมูล**: ทอง (Candle Lab, M5 ต่อเนื่อง 2009-03..2026-09 สร้าง M5 / M15 / M30 / H1 / H4 / D1) แบ่ง DEV 2009–15 และ
  CHECK 2016–26; เงิน 2010–26 (ตลาดอิสระ); 15 ตลาด MT5 (EURUSD USDJPY AUDUSD USDCHF US500 USTEC USOIL BTCUSD DE30 JP225 XCUUSD XPTUSD
  USDCNH USDMXN USDZAR; ไม่รวม USDINR) — D1 / H1 2016–26, H4 รวมจาก H1, M30 2016–26 (ไม่มี JP225), M15 2022–26, M5 2025–26.
- **ต้นทุน**: ทอง 2.5 bp, เงิน 11.6 bp, ตลาด MT5 = spread มัธยฐาน + 1 bp (`data/bundle/broker_specs.json`) + swap จริง.
- **การเข้า-ออก**: สัญญาณรู้ตอนแท่งปิด; คำสั่ง market เข้าที่ราคาเปิดแท่งถัดไป; คำสั่ง limit ได้เมื่อราคาแตะ (ได้ราคาที่ limit หรือราคาเปิดถ้าดีกว่า);
  ถ้าแท่งที่ได้ limit แตะ SL ด้วย ถือว่าโดน SL ในแท่งนั้น; ในแท่งเดียว SL มาก่อน TP เสมอ; ออกตามราคาปิดจะออกที่ราคาเปิดแท่งถัดไป;
  ราคากระโดดข้าม SL ได้ราคาเปิด; ถ้าราคาเข้าเลย TP หรือ SL ไปแล้ว ข้ามไม้นั้น.
- **R** = ระยะจากราคาเข้าถึง SL; R สุทธิหักต้นทุนและ swap แล้ว.
- **จุดออก 2 แบบทุกแผน**: "ตามคลิป" (TP ตามกฎผู้สอน) และ "ไม่จำกัด" (ไม่มี TP; ออกเมื่อปิดเลย best − 3 × ATR22 ของ TF นั้น, SL แรกยังอยู่).
  กฎคัทขาดทุนเร็วของผู้สอน (ถ้ามี) ใช้ทั้งสองแบบ.
- **ตัวเปรียบเทียบ**: สุ่มแท่งเข้าในตลาด / TF / ช่วงเดียวกัน ทิศเดียวกัน ระยะ SL และ TP เป็นจำนวน ATR14 เท่าไม้จริง เข้าแบบ market; แผนที่ผูกกับเวลา
  ใช้เวลาของวันเดียวกัน; 20 รอบ รอบละ min(n, 2,000) ไม้ที่สุ่มจากพารามิเตอร์ไม้จริง → excess = R จริง − R เปรียบเทียบ.
- **ตัวเลขที่รายงาน**: n, ไม้ต่อปี, อัตราชนะ, ชนะ / แพ้เฉลี่ย (R), R สุทธิ, R ก่อนต้นทุน, R เปรียบเทียบ, excess, p แบบ bootstrap รายสัปดาห์
  (ด้านเดียว) ของ R > 0 และ excess > 0; อัตราชนะที่ผู้สอนอ้าง เทียบกับที่วัดได้.
- **เกณฑ์ผ่าน (ต่อแผน × TF × แบบ × จุดออก)**: ทอง CHECK R สุทธิ > 0 และ excess > 0 โดย max(p) < 0.05 หลัง Holm ทุกการทดสอบของแผนนั้น
  และ ทอง DEV R > 0 และ เงิน R > 0 และ R > 0 ใน ≥ 60 % ของตลาด MT5 ที่มีไม้ ≥ 30 (ถ้ามีตลาดเข้าเกณฑ์ < 5 ตลาด ใช้ทอง + เงินอย่างเดียว).
- ห้ามมาร์ติงเกล / กริด / ถัวขาดทุน; ไม่จำกัดกำไรนอกเหนือจากกฎของผู้สอน; ผลลบรายงานตามจริง.
