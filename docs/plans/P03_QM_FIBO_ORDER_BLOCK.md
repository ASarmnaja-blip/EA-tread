# P03 QM pattern + Fibonacci 50 / 61.8 / 88.6 + Order Block (คลิป 0)
- TF M5 (หลัก) และ M15. Swing fractal 2 (รู้หลัง 2 แท่ง).
- ขาย: swing ต่อเนื่อง H1 → L1 → H2 → L2 โดย H2 > H1 และ L2 < L1; รู้ตอน L2 ยืนยัน (แท่ง c).
- Fibo ของขา H2→L2: ระดับ x = L2 + x (H2 − L2). Limit ขายที่ x = 0.5 และ 0.618 (2 ไม้แยกกัน); SL ที่ x = 0.886; TP แต่ละไม้ = RR 1:1.
- Order Block (หลัก): มีแท่งเขียวในขา H2→L2 ที่เนื้อเทียนซ้อนกับช่วง [0.5, 0.618]. แบบรอง: ไม่ต้องมี.
- ทิศเทรนด์ (หลัก): H1 อยู่ใต้จุดกึ่งกลาง Donchian 55 แท่ง สำหรับขาย. แบบรอง: ไม่ใช้.
- Limit ใช้ได้ 96 แท่ง M5 (32 แท่ง M15) และยกเลิกถ้าราคาไปถึง TP ของไม้ 50 % ก่อนได้ไม้ หรือทะลุ H2. ซื้อกลับด้าน.
- รายงานแบบไม้เดียวที่ 50 % แยก; อัตราชนะที่ผู้สอนอ้าง 80–90 %.
