# P12 ปิดหลุดแนวรับหลังทำยอด + Clean Traffic (คลิป 3 ท่า 1)
- TF M5, M15, H1. swing low ยืนยัน 2 จุดล่าสุดยกตัว (L1 < L2), swing high H หลัง L2.
- สัญญาณ: close(t) < L2 (แนวรับก่อนหน้า) ครั้งแรกหลัง H → ขาย market. SL (หลัก) = H + 0.1 ATR; แบบรอง = high(t) + 0.1 ATR. TP 1:1.
- Clean Traffic (หลัก): ในขาจาก L2 ถึง H แท่งสวนทาง ≤ 20 % และ efficiency ratio (|ปิดปลาย − ปิดต้น| / Σ|การเปลี่ยนแปลงของราคาปิด|) ≥ 0.6.
  แบบรอง: ไม่ใช้. ซื้อกลับด้าน.
