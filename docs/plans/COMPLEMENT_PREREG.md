## วิธีเลือก (ใช้ข้อมูลช่วงแรกเท่านั้น)

**ช่วงเลือก:** ก.ย. 2009 – ธ.ค. 2017 (ทองและเงิน ช่วงนี้ยังไม่มี BTC)

- **เดือนที่ A แพ้:** เดือนที่ R รวมของ A (นับตามเดือนที่ปิดไม้) ติดลบ
- **เลือก B:** แบบที่ทำ R รวมในเดือนที่ A แพ้ได้มากที่สุด
  - เงื่อนไข: ทั้งช่วงเลือกต้องได้ R รวม > 0 และมีไม้อย่างน้อย 30 ไม้
- **เดือนที่ A และ B แพ้พร้อมกัน:** เดือนที่ R ของทั้งคู่ติดลบ
- **เลือก C:** แบบที่ทำ R รวมในเดือนนั้นได้มากที่สุด ใช้เงื่อนไขเดียวกับ B

## วิธีทดสอบ

**ช่วงทดสอบ:** ม.ค. 2018 – ก.ย. 2026 ใช้ทั้ง 3 ตลาด และไม่ได้ใช้ข้อมูลช่วงนี้ในการเลือก

**รายงาน:**
- A, B, C แยกกัน และพอร์ตรวม A+B+C 2 แบบ
  - แบบละ 0.33% (เสี่ยงรวมเท่ากับรูปแบบเดียวที่ 1%)
  - แบบละ 1%
- สัดส่วนของเดือนที่ A แพ้ แล้ว B ชนะ
- สัดส่วนของเดือนที่ A และ B แพ้ แล้ว C ชนะ
- ความสัมพันธ์ของผลรายเดือน
- ผลในช่วงปี 2018 และ 2022
- ผลทั้งช่วง 2009–2026 รายงานไว้เป็นข้อมูลเท่านั้น เพราะช่วง 2009–2017 ใช้เลือกแล้วจึงเอียง

## เกณฑ์ (กำหนดก่อนรัน)

**B และ C "ใช้ได้จริง" เมื่อผ่านทั้ง 3 ข้อในช่วงทดสอบ:**
1. R รวม > 0
2. ชนะในเดือนที่ต้องชนะ (เดือนที่ A แพ้ สำหรับ B / เดือนที่ A และ B แพ้ สำหรับ C) มากกว่า 50% ของเดือนเหล่านั้น
3. พอร์ตรวมที่ 0.33% ต่อแบบ มี Equity DD ต่ำกว่า A อย่างเดียวที่ 1% ในช่วงเดียวกัน

**ข้อควรระวัง:** กองตัวเลือกมีทั้งหมด 180 แบบ ผลในช่วงเลือกจึงเอียงจากการคัดเลือก ช่วงทดสอบคือผลที่ใช้ตัดสิน
