# Tool Foundry — สถานะล่าสุด (อัปเดตระหว่างลูป)

> ไฟล์นี้สรุปให้ผู้ใช้อ่าน รายละเอียดทุกตัวเลขอยู่ใน `docs/FOUNDRY_LEDGER.md`
> กติกาอยู่ใน `docs/FOUNDRY_PROTOCOL.md` ยังไม่มีเครื่องมือผ่านครบทุกด่าน **ยังไม่มีข้อเสนอให้ใช้งาน**

## ลองไปแล้ว (ณ 2026-09-30 หลังรอบ 24)
- ลองไปแล้ว 2,981 แบบ (setup × พารามิเตอร์ × สภาพตลาด × ทิศทาง) ทุกแบบนับไว้ในบัญชี
- ส่งเข้าด่านตรวจ (VAL 2015–2020) 11 ครั้ง ตกทั้ง 11 ครั้ง
- ด่านสุดท้าย (HOLD 2021–2026) ยังไม่ถูกเปิดดูเลย

## สิ่งที่รู้แล้ว
1. **setup ตายตัวใช้ไม่ได้ข้ามยุค** ทุกอย่างที่ได้ผลช่วง 2003–2014 (NR7, การตามแรง, การทะลุกรอบรายสัปดาห์) แบนหรือติดลบในช่วง 2015–2020
2. **setup แบบสวนแรง (mean reversion) ขาดทุนแทบทุกสภาพตลาด** ส่วนแบบตามแรงได้เปรียบเฉพาะยุคแรก
3. **การเลือก setup จากผลงานล่าสุดทุกวันศุกร์ใช้ได้จริง** (แบบ Champion/Challenger ตาม WPWB) กลุ่มที่ติดอันดับต้นๆ ทำได้ดีกว่าค่าเฉลี่ยทั้งชุดประมาณ +0.05 ถึง +0.06R ต่อหน่วย และผลนี้ยืนยันนอกข้อมูลที่ใช้ค้นหาถึง 4 ครั้ง (t 2.1, 2.3, 3.3, 3.3)
4. **แต่ผลสุทธิยังบางเกินไป** ทั้งชุด setup โดยเฉลี่ยทำได้ประมาณ 0 ก่อนหักต้นทุน ต้นทุนที่ตั้งไว้ 2 bp ต่อรอบ (สองเท่าของ Exness จริง) จึงเหลือผลสุทธิช่วง 2015–2020 ประมาณ +0.03R (t 1.5) ยังไม่ถึงเกณฑ์
5. **การรู้ระดับความผันผวนของ WPWB ไม่ได้ช่วยเลือก setup** แต่การงดเทรดสัปดาห์ CALM ช่วยได้เล็กน้อย

## ตัวที่ใกล้ที่สุด
`TOPQ_L104_EW_NOTCALM` ทุกวันศุกร์จัดอันดับ setup ทั้ง ~180 ตัวด้วยผลงาน 104 สัปดาห์ แล้วเทรดกลุ่ม 20% บนสุดในสัปดาห์ถัดไป ให้ความเสี่ยงเท่ากันต่อ setup และงดเทรดสัปดาห์ที่ WPWB บอกว่า CALM
- ช่วงค้นหา 2003–14: +0.063R ต่อหน่วย, t 2.89, ประมาณ +62R ต่อปี
- ช่วงตรวจ 2015–20: +0.034R ต่อหน่วย, t 1.48, p 0.069, ประมาณ +39R ต่อปี (**ไม่ผ่าน** เกณฑ์ตอนนั้นคือ p < 0.0046)
- R ต่อปีนับจาก 1R ต่อ setup ต่อสัปดาห์ ถือพร้อมกันหลายตัว ยังไม่ได้แปลงเป็นความเสี่ยงของพอร์ตจริง

## กำลังทำอะไรต่อ
หาวิธีเพิ่มผลสุทธิของทั้งชุด setup โดยไม่ลดสมมติฐานต้นทุน ทุกครั้งที่ลองใหม่ เกณฑ์ผ่านจะเข้มขึ้นเอง

## อัปเดตหลังรอบ 16–24
- ลองแล้ว ไม่ช่วย: ถือนานขึ้น, trailing stop, กรองด้วยเทรนด์รายวัน, ตั้ง OCO ตามความผันผวนที่ WPWB คาด, ทะลุกรอบเมื่อจังหวะแกว่งช้ากว่าคาด, ชุด setup ใหญ่ขึ้น (สูงสุด 414 ตัว), วิธีจัดอันดับแบบอื่น, งบความเสี่ยงคงที่ต่อสัปดาห์, จัดอันดับด้วยต้นทุนแบบเครียด, ถือกลุ่มที่เลือกไว้ 4 สัปดาห์
- **ตัวเลือกทุกแบบติดเพดานเดียวกัน** คือช่วงค้นหา t ประมาณ 2.7–2.9 (Sharpe ประมาณ 1 ต่อปี) และช่วงตรวจ t ประมาณ 1.3–1.5 (Sharpe ประมาณ 0.6)
- **หน้าต่างสั้นตาม CLAUDE.md ข้อ 5 (3–5 วัน หรือ 1–4 สัปดาห์) ใช้เลือก setup ได้แย่กว่าหน้าต่าง 52–104 สัปดาห์** ข้อมูลจริงไม่สนับสนุนการเปลี่ยนเครื่องมือเร็วๆ
- **เปิดบันทึกล่วงหน้าแบบ shadow แล้ว** (`docs/FOUNDRY_SHADOW_PREREG.md`) ตัวเลือกที่ดีที่สุดจะเลือก setup ทุกวันศุกร์และบันทึกผลแบบกระดาษ ไม่ส่งคำสั่ง เริ่มนับจริงรอบ 2 ต.ค. รอบซ้อมสัปดาห์นี้เลือกได้ 36 setup ส่วนใหญ่ฝั่ง Buy หรือตามเทรนด์ เพราะทองขาขึ้นมาตลอดปี 2024–2026
