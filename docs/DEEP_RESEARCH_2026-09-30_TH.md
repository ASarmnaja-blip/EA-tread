# รายงานค้นคว้าเชิงลึก: ทำไม WRWR ยังไม่ทำเงิน และช่องทางที่ยังไม่เคยแตะ (2026-09-30)

ผู้ใช้สั่งว่า ถ้าผลยังติดลบหรือยังไม่ถึงครึ่งเป้า ให้คิดนอกกรอบ หาช่องโหว่ และค้นคว้าเชิงลึก ทั้งจุดที่ไม่คาดคิด จุดที่ไม่เคยแตะ
และเทคนิคที่กองทุนเชิงปริมาณใช้

ผลตอนนี้ยังไม่ถึงครึ่งเป้า (150R/ปี) และยังไม่ถึงระดับ "ใช้ได้" (10R/ปี) ด้วย รายงานนี้จึงรวม 3 เรื่อง คือ
1. สิ่งที่ข้อมูลของเราเองบอก
2. คลังไอเดียจากงานวิจัยทั่วโลก เทียบกับสิ่งที่เราเคยทดสอบแล้ว
3. ลำดับงานถัดไป

หลักเดิมทุกข้อยังบังคับใช้: ห้าม Grid/Martingale/ถัวเฉลี่ย, ต้องประกาศเกณฑ์ก่อนรัน, หักต้นทุนจริงทุกครั้ง และห้ามใช้เงินจริงถ้าผู้ใช้ไม่ยืนยันทีละออเดอร์

## 2. สิ่งที่ข้อมูลของเราเองบอก (ช่องโหว่ที่เจอ)

1. **กำไรก่อนต้นทุนที่เห็นในอดีต ส่วนใหญ่เกิดจากการเลือกหลังเห็นผล**
   - ถ้าเลือกชุดกฎหลังเห็นผล (in-sample) ชุด shadow ของทองได้กำไรก่อนต้นทุน +58 ถึง +189R
   - แต่ถ้าเลือกแบบไม่รู้อนาคต กำไรก่อนต้นทุนของทองเป็น **−32R** และของเงินแค่ **+9R** จากนั้นต้นทุนกินอีกราว −48 ถึง −52R
   - แปลว่า **ลดต้นทุนอย่างเดียวช่วยไม่ได้** เพราะทองแบบไม่รู้อนาคตติดลบตั้งแต่ก่อนหักต้นทุนแล้ว
2. **ชนะไม้สุ่มไม่ได้แปลว่าทำเงิน** ไม้สุ่มแย่มากเพราะโดนต้นทุนเต็มๆ ตัวเลือกของ WRWR แค่หลบตัวที่ต้นทุนแพงได้ดีกว่า เป้าที่ต้องชนะจริงคือ "ศูนย์หลังหักต้นทุน" และ "ถือทองเฉยๆ"
3. **กำไรที่มีมาจากแนวโน้มขาขึ้นของตลาด ไม่ใช่ฝีมือจับจังหวะ** ทั้งทองและเงิน ไม้ซื้อได้บวกราว +0.07 ถึง +0.16R/ไม้ ขณะที่ไม้ขายติดลบ
4. **การเลือกชุดกฎไม่เสถียร** PBO ของทอง 0.45 และของเงิน 0.83 (ค่าสูงแปลว่าชุดที่ดูดีที่สุดในอดีตมักไม่ดีในช่วงถัดไป) ดังนั้นไม่ควรฝากทุกอย่างไว้กับชุดเดียว
5. **ข้อมูลที่ใช้เกือบทั้งหมดคือราคาอย่างเดียว** ทุกแบบที่ลองมาราว 4,000 กว่าแบบ ล้วนเป็นการจัดรูปใหม่ของแท่งราคาเดิม ซึ่งผู้เล่นมืออาชีพใช้กันหมดแล้ว ต้องเพิ่ม **ข้อมูลชนิดอื่น** (สถานะของกองทุน, options, flow, macro) หรือ **กลไกเชิงโครงสร้าง** (ที่วางคำสั่ง, ช่วงเวลาที่ถูกบังคับให้เทรด)
6. **ของที่เคยใช้ได้ก็เสื่อม** ช่วงเอเชียที่ทองมักขึ้น ใช้ได้ปี 2003–2015 แล้วหายไป (Part 49, HOD21) สอดคล้องกับงานวิจัยที่พบว่า "overnight drift" ของหุ้นก็หายไปหลังปี 2021
7. **หลักฐานรายสัปดาห์ต้องใช้เวลานาน** ในช่วง 130 สัปดาห์ edge ที่ทายทิศถูก 60% จะตรวจเจอแค่ 22% ของครั้ง บันทึก 26 สัปดาห์จึงพิสูจน์อะไรไม่ได้ ต้องใช้ข้อมูลอิสระ (สินทรัพย์อื่น/ช่วงเวลาอื่น) แทนการรอ
8. **จุดเล็กในโมเดลต้นทุน:** ข้อมูล Treasury มีตั้งแต่ปี 2016 swap ก่อนปี 2016 จึงใช้ดอกเบี้ย 2 ปีของต้นปี 2016 แทน ทำให้ swap ปี 2004–07 ต่ำไป และปี 2009–15 สูงไปเล็กน้อย ผลกระทบรวมไม่กี่ R ส่วน slippage 1 bp เป็นค่าสมมติที่ยังไม่เคยวัดจริงบนบัญชี

## 4. เทคนิคที่กองทุนเชิงปริมาณใช้

- **ตรวจว่า backtest overfit หรือไม่**
  - มีแล้ว: White Reality Check, PBO/CSCV, walk-forward, ประกาศเกณฑ์ก่อนรัน, ข้อมูลปลอมแบบ placebo
  - ยังไม่มี:
    - Hansen SPA: ตรวจเจอ edge จริงได้ดีกว่า Reality Check เมื่อมีชุดกฎแย่ปนอยู่มาก
    - Deflated Sharpe Ratio
    - CPCV แบบเต็ม
    - Model Confidence Set
- **สร้างสัญญาณ**
  - Meta-labeling: ชั้นที่สองตัดสินว่าจะรับสัญญาณไหนและขนาดเท่าไร
  - รวมสัญญาณอ่อนหลายตัวเข้าด้วยกัน แทนการเลือกตัวเต็งแค่ 1–2 ตัว
  - **กระจายหลายตลาด**: ตามกฎของ Grinold IR = IC × √breadth คือ edge เล็กในหลายตลาดรวมกันแล้วใหญ่ขึ้น
  - เทรดโดยคำนึงต้นทุน (Gârleanu–Pedersen): ตั้งเป้าสถานะล่วงหน้า แล้วขยับเข้าหาทีละส่วน และมีช่วงที่ไม่เทรดเลย
  - ใช้ bandit (Thompson sampling) สลับ champion กับ challenger
- **ข้อมูลทางเลือก:** COT, options (VRP, skew, gamma), flow เข้าออก ETF, premium ของ SGE, ข่าวที่วิเคราะห์ด้วย NLP
- **การส่งคำสั่ง:** วัด fill และ slippage จริง, ใช้ limit order, เลือกประเภทบัญชี
  - บัญชี Raw Spread ของ Exness คิดค่าคอม XAUUSD $3.5/lot/ข้าง คือราว 0.2 bp ไป-กลับที่ราคา $3,800 บวก spread ดิบ
  - อาจถูกกว่าที่โมเดลเราคิด (ขั้นต่ำ 2 bp) ในปีหลังๆ แต่ต้องวัดจริงก่อน

## 5. จุดที่ไม่เคยแตะ เรียงตามความน่าคุ้ม

1. **โมเดลรายสัปดาห์ที่ใช้ข้อมูลหลายชนิด:** ตามแนวโน้ม (TSMOM) + VRP จาก GVZ + สถานะใน COT + ดอกเบี้ยจริงและ DXY ทดสอบทั้งทองและเงิน ถือ 1 สัปดาห์ และมีช่วงไม่เทรด
   - ใช้ข้อมูลชนิดใหม่ที่ไม่ใช่ราคา
   - ต้นทุนต่อไม้ต่ำมากเมื่อเทียบกับการแกว่งรายสัปดาห์ (2 bp เทียบกับ ~200 bp)
   - ข้อเสีย: R ต่อปีจะไม่สูง แม้ edge ดีก็อาจได้ราว 3–10R/ปี
   - ต้องขออนุญาตโหลด CFTC ย้อนหลังปี 2004–2014 และ Treasury ปี 2003–2015 (ไฟล์เล็ก จากเว็บทางการ cftc.gov / treasury.gov)
2. **กลไกเลขกลมแบบ Osler:** แยกเป็น 2 เหตุการณ์ คือ "แตะครั้งแรกแล้วเด้ง" (เพราะ TP กองอยู่) กับ "ทะลุเลยไปแล้วเร่ง" (เพราะ SL ถูกกวาด) ใช้ M1 ตั้งแต่ปี 2009 และข้อมูลพร้อมแล้ว
3. **วัดต้นทุนจริงบน Demo:** วัด fill, slippage และ spread ตามช่วงเวลา ขนาด 0.01 lot ติดป้าย EXECUTION TEST ONLY ตามสิทธิ์ที่มีอยู่ จำเป็นสำหรับทุกกลยุทธ์ระดับ H1
4. **Meta-labeling บนสัญญาณ Family 2:** ความสำคัญลดลง เพราะกำไรก่อนต้นทุนแบบไม่รู้อนาคตใกล้ศูนย์ ตัวกรองจะช่วยได้ก็ต่อเมื่อมีกลุ่มย่อยที่มี edge จริง
5. **Flow เข้าออก GLD และ premium ของ SGE:** ต้องโหลดข้อมูลเพิ่ม
6. **ตะแกรง C11:** ค้นกว้างที่สุดว่า "ตัวแปรไหน ระดับเท่าไร" แต่แพงที่สุด ต้องรันข้อมูลปลอม 999 เส้นทาง ใช้คอมราว 2 ชม. ขึ้นไป
7. **ขยายไปหลายตลาด** (FX, ดัชนี ผ่าน Dukascopy): เพิ่ม breadth ตามหลักกองทุน แต่ออกนอกทอง ต้องให้ผู้ใช้ตัดสินใจ

## 6. ทางลัดที่ดูเหมือนช่องโหว่แต่เป็นกับดัก (ห้ามหรือไม่แนะนำ)

- **Grid, Martingale, ถัวเฉลี่ย:** ห้ามตาม CLAUDE.md เพราะแค่ซ่อนการขาดทุนไว้จนวันที่พอร์ตแตก
- **ใช้ระบบป้องกันยอดติดลบของโบรกเล่นเลเวอเรจสูงก่อนข่าว:** เป็นการพนัน ค่าคาดหวังติดลบหลังต้นทุน และเสี่ยงผิดเงื่อนไขโบรกเกอร์
- **Latency arbitrage (อาศัยราคาของโบรกที่ช้ากว่าตลาด), เก็บโบนัส, hedge ข้ามบัญชี:** ผิดเงื่อนไขและโดนปิดบัญชี
- **EA "holy grail" ที่ backtest สวย:** มักใช้ spread คงที่หรืออินดิเคเตอร์ที่เปลี่ยนค่าย้อนหลัง (repaint) ซึ่งเราเคยจับได้หลายครั้งแล้ว

## 7. เทียบกับความจริงของมืออาชีพ

- **สูตรพื้นฐาน:** R ต่อปี = จำนวนไม้ × edge ต่อไม้
  - เทรดถี่ ต้นทุนจะกิน edge (M5 เสียราว 0.26R/ไม้, H1 0.06–0.16R)
  - เทรดห่าง ได้ R ต่อปีน้อย
- **ตัวเลขจริงของมืออาชีพ**

  | ผู้เล่น | ผลงาน |
  |---|---|
  | Renaissance Medallion (ดีที่สุดในประวัติศาสตร์) | ราว 66%/ปีก่อนค่าธรรมเนียม และราว 39–40% หลังค่าธรรมเนียม (1988–2018) ใช้หลายพันตลาด ความถี่สูงมาก และเลเวอเรจ |
  | ดัชนี CTA ของ Société Générale | ราว 4.8%/ปี (2000–2024) |
  | CTA ชั้นดี | Sharpe 0.8–1.5 |
  | บัญชี CFD รายย่อย | 74–89% ขาดทุน (ESMA) |

- **เทียบกับเป้าของเรา**
  - 300R/ปีที่เสี่ยง 1%/ไม้ ≈ +300%/ปีแบบไม่ทบ (ราว 7 เท่าของ Medallion หลังค่าธรรมเนียม)
  - ครึ่งเป้า 150R ≈ +150%/ปี ยังไม่มีหลักฐานว่าทำได้จากทองตัวเดียว
  - เป้าที่มีหลักฐานว่าเป็นไปได้คือ 10–25R/ปี (ราว 8–25%/ปีแบบทบต้น) และต้องเจอ edge จริงก่อน
