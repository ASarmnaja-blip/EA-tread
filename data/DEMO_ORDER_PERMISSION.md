# Demo order test permission

ผู้ใช้อนุญาตให้ส่งคำสั่งซื้อขายเพื่อทดสอบระบบได้เมื่อจำเป็น **เฉพาะบัญชี Demo เท่านั้น**

ข้อบังคับก่อนและระหว่างการทดสอบ:

1. ตรวจจาก MT5 API ทุกครั้งว่า `account_info().trade_mode` เป็น Demo และ server เป็นบัญชีทดลอง หากตรวจไม่ได้หรือไม่ใช่ Demo ให้ยกเลิกทันที
2. ใช้ขนาดต่ำสุดที่โบรกอนุญาต ปัจจุบันคือ 0.01 lot และเปิดได้ครั้งละไม่เกินหนึ่งสถานะ
3. ต้องกำหนด Stop Loss ตั้งแต่ส่งคำสั่ง ห้าม Grid, Martingale, เพิ่มไม้แก้ขาดทุน หรือถัวเฉลี่ย
4. ใช้เพื่อทดสอบเส้นทางคำสั่ง, spread, slippage, fill, stop/exit และ logging เท่านั้น ไม่ใช่เพื่อพิสูจน์ edge จากผลไม่กี่ออเดอร์
5. ปิดสถานะทดสอบเมื่อเก็บหลักฐานครบหรือเมื่อหมดเวลาทดสอบ ห้ามปล่อยค้างโดยไม่มีเงื่อนไขหมดอายุ
6. บันทึก request, result code, เวลา, ราคาเสนอ, ราคาที่ fill, spread, slippage, SL, exit และเหตุผลที่เปิด/ปิดทุกครั้ง
7. หากตลาดปัจจุบันเป็น NO TRADE แต่จำเป็นต้องทดสอบ execution ให้ติดป้ายชัดเจนว่า `EXECUTION TEST ONLY` และผลต้องไม่ถูกนับเป็นผลงานของกลยุทธ์
8. สิทธิ์นี้ไม่ครอบคลุมบัญชีเงินจริง และห้ามเปลี่ยนไปใช้บัญชีจริงโดยอัตโนมัติ

## บันทึกเพิ่ม 2026-09-27 — ผู้ใช้สั่งให้เปิดคำสั่งจริงบนบัญชีเดโม่

ผู้ใช้สั่งในแชตว่า "ให้เปิดคำสั่งจริงได้เลยเพราะบัญชีที่ใช้นั้นคือบัญชีเดโม่จึงไม่ส่งผลเสียใดๆ"

ขอบเขตที่ Claude ตีความและบังคับใช้:

- ใช้เฉพาะ `research/pilot/payoff_demo_autotrader.py` แบบ `--live --loop` ตัวเดิมของ Codex
  (ระบบอัตโนมัติวันพุธ/เสาร์ระบุว่า "frozen Demo autotrader") ไม่แก้กฎหรือพารามิเตอร์
- **ข้อ 2 (ครั้งละหนึ่งสถานะ) ถูกผ่อนเฉพาะ autotrader ตัวนี้** ตามคำสั่งผู้ใช้ เพราะออกแบบให้
  ทุกสัญญาณ A/B/C มี SL/TP ของตัวเองบนบัญชี hedging ข้ออื่นทั้งหมดยังบังคับ
- ตรวจ `ACCOUNT_TRADE_MODE_DEMO` ทุกรอบ (มีในโค้ดแล้ว), ขนาด `volume_min` (0.01), SL ทุกคำสั่ง,
  หยุดเปิดไม้ใหม่และปิดทุกไม้เมื่อ DD ถึง 40%, ปฏิเสธเมื่อ spread เกิน 0.135
- ห้าม Grid, Martingale, ถัวเฉลี่ย หรือเพิ่มไม้แก้ขาดทุน
- ผลที่ได้เป็น **การสังเกตล่วงหน้าบนเดโม่** เก็บเป็นหลักฐานตามกฎข้อ 9 ไม่ได้พิสูจน์ edge
  จากไม่กี่ไม้ และห้ามใช้เป็นเหตุผลย้ายไปบัญชีเงินจริง
- สิทธิ์นี้ **ไม่ครอบคลุมบัญชีเงินจริง** การส่งคำสั่งเงินจริงยังต้องขอยืนยันจากผู้ใช้ทุกครั้ง
